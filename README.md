# Employee Attrition Prediction System

## Project Overview
An end-to-end machine learning pipeline that predicts whether an employee is likely to leave a company, based on workplace, performance and demographic factors. It covers data generation, cleaning, EDA, visualisation, model training with hyperparameter tuning, evaluation, and a prediction interface (console + Streamlit).

## Technologies Used
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Joblib, Streamlit

## Dataset Description
Synthetic HR dataset (1,500 employees, ~15% attrition -> imbalanced), generated by `src/generate_data.py`. About 2% of values are intentionally missing in several columns.

| Feature | Description |
|---|---|
| EmployeeID | Unique identifier (dropped before training) |
| Age | Employee age |
| Department | Sales / Engineering / HR / Marketing / Finance |
| MonthlyIncome | Salary in ₹ |
| YearsAtCompany | Tenure in years |
| JobSatisfaction, WorkLifeBalance, PerformanceRating | Scores 1-5 |
| OverTime | Yes / No |
| DistanceFromHome | Distance in km |
| Attrition | Target (Yes / No) |

## Methodology
- **Preprocessing:** median imputation + StandardScaler for numeric features; most-frequent imputation + One-Hot Encoding for categorical features.
- **Class imbalance:** `class_weight="balanced"` for Logistic Regression and Random Forest.
- **No data leakage:** stratified 80/20 split first; all preprocessing is inside a scikit-learn `Pipeline`, so it is fitted only on training folds.
- **Tuning:** `GridSearchCV` (5-fold stratified CV, scoring = ROC-AUC).
- **Model selection:** best cross-validated ROC-AUC (test set kept untouched for final evaluation).

## Model Performance Comparison (test set)
| Model | Accuracy | Precision | Recall | F1-score | ROC-AUC |
|---|---|---|---|---|---|
| Logistic Regression | 0.6867 | 0.2870 | 0.7333 | 0.4125 | 0.8058 |
| Random Forest | 0.7600 | 0.3373 | 0.6222 | 0.4375 | 0.7835 |
| Gradient Boosting | 0.8567 | 0.6667 | 0.0889 | 0.1569 | 0.7356 |

**Best model: Logistic Regression.** It has the highest ROC-AUC (cross-validated and on the test set) and the best recall (0.73), which matters most here: missing an employee who will leave is costlier than a false alarm. Gradient Boosting has high accuracy only because it predicts "Stay" almost every time on this imbalanced data.

## Key Insights from EDA
- Overall attrition is about 15% (imbalanced data).
- Employees working **overtime** leave at roughly twice the rate of those who don't (about 24% vs 11%).
- Attrition falls steadily as **job satisfaction** rises (about 24% at score 1 vs 6% at score 5).
- **Sales** has the highest attrition; **Engineering** and **Finance** the lowest.
- Strongest correlations with attrition: MonthlyIncome (negative), YearsAtCompany (negative), JobSatisfaction (negative).
